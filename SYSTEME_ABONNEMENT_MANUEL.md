# 🔐 SYSTÈME D'ABONNEMENT MANUEL (APK + Gestion Admin)

## 🎯 VOTRE WORKFLOW RÉEL

```
1. Client contacte vous → Veut l'app
2. Client paie (espèces ou virement RIB)
3. VOUS activez son compte depuis dashboard admin web
4. Client télécharge APK et installe sur tablette
5. App vérifie l'accès en temps réel via Supabase
6. Si abonnement OK → App fonctionne
7. Si expiré/suspendu → App bloquée
```
